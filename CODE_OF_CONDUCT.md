# Code of Conduct

We want Domain Renewal Radar to be a welcoming project for contributors of all backgrounds. Be respectful, specific, and constructive in issues, reviews, discussions, and pull requests.

Harassment, discrimination, personal attacks, deliberate secret exposure, malicious code, and disruptive behavior are not acceptable. Maintainers may remove content or restrict participation when necessary to keep the project safe and productive.

If a concern cannot be resolved in public, contact the repository owner privately through the security reporting channel described in `SECURITY.md`.
